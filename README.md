# Focused Growth Tracker

A minimalist lifelong learning habit builder designed to help continuous learners organize their technical education goals, track completion metrics, and turn daily roadblocks into documented feedback loops.

## Features

* **Milestone Tracker**: Categorize and track technical learning objectives across domains like Programming, Algorithms, Web Development, and System Design, complete with live progress calculations.
* **Mistake-to-Lesson Journal**: Log technical roadblocks alongside actionable takeaways to build a permanent, searchable record of growth.
* **Oatmeal & Plum Aesthetic**: Styled with custom native palettes (`#F5EFEB` backgrounds and `#6A2C59` plum accents) for a clean, professional, and distraction-free interface.

## Tech Stack

* **Language**: Python
* **Framework**: Streamlit
* **Database**: SQLite
